UserProjector — builds the users_view read model from User events.

Pure event handler: receives an Event + a ReadModelStore and emits a single version-gated upsert (or delete on UserDeleted). Holds no mutable state. Idempotency comes from the store’s version gate, not from the projector — replaying a known event sequence twice yields the same users_view because each upsert with a given version is rejected the second time.

Wired into InProcessEventBus at startup via a thin EventHandler adapter that calls ProjectionEngine::process.
