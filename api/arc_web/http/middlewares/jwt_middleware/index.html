JWT bearer auth (HIPAA-4 aware).

On every request:

  1. Decode and signature-verify the bearer token.
  2. Check jti against the server-side SessionStore. Revoked / unknown → 401. Store unavailable → fail closed with 503.
  3. Insert (actor_id, jti) into request extensions for handlers.

Tokens minted before HIPAA-4 landed have no jti. Set JWT_GRANDFATHER_LEGACY=true to accept them during rollout; defaults to refusing such tokens.
