Enums§

DatabaseDriver
Storage backend selected at startup behind the EventStore / ReadModelStore traits. Parsing is always available; constructing the Postgres stores additionally requires the postgres cargo feature.

DEFAULT_DATABASE_URL
Default database file path used when DATABASE_URL is not set
DEFAULT_POOL_LIMIT
Default database connection pool size
DEFAULT_SESSION_DATABASE_URL
Default SQLite file backing the JWT session-revocation registry when the primary driver is not SQLite.
DEFAULT_USER_SNAPSHOT_INTERVAL_EVENTS
Default number of new aggregate events between best-effort user snapshots.

Functions§

database_pool_limit
Get the database pool limit from environment or use default
database_url
Get the database URL from environment or use default
event_integrity_key
Optional HMAC key enabling HIPAA-5 event integrity signing/enforcement. The storage layer validates length and rejects keys shorter than 32 bytes.
event_integrity_key_id
Identifier stored with each event signature so future key rotation can distinguish which key signed a row.
session_store_url
SQLite URL backing the JWT session-revocation registry. The registry is SQLite-only today; under a non-SQLite primary driver it keeps its own local SQLite database (overridable via SESSION_DATABASE_URL) so session revocation still functions.
user_snapshot_interval_events
Number of new events between best-effort aggregate snapshots. Values <= 0 disable user snapshots without changing command correctness.
