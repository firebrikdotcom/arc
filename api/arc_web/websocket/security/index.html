arc_web::websocket

Module security 

Source
Expand description

Authentication and authorization seams for WebSocket connections.

The runtime deliberately knows neither the authentication plugin nor its session format. Plugins provide a verified principal, and the server’s room policy decides which rooms that principal may join.
