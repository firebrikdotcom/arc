Expand description

Server-side registry of issued JWTs.

Implementations:

  • InMemorySessionStore — Arc<Mutex<HashMap>>, ships in this crate behind test-utils and is also a viable single-node production option
  • SqliteSessionStore — in arc-es-sqlite, durable
  • Future: Postgres, Redis

Record a freshly-minted token. Called by the login controller before it returns the token to the client; on failure, the controller must refuse to hand out the token.

Mark the session revoked. Idempotent; revoking an unknown jti returns Err(NotFound) so callers can distinguish “already gone” from “double revoke” if they care.
