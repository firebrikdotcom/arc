Struct InMemoryReadModelStore

pub struct InMemoryReadModelStore { /* private fields */ }
Expand description

In-memory read model store for testing.

Stores rows keyed by primary key in a per-table HashMap. Implements the version gate exactly the way SQLite does, so tests written against this store exercise the same idempotency semantics as production.
