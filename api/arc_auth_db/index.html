Database identity provider for Arc: users, roles, user_roles and browser_sessions, bootstrapped by DbIdentityPlugin setup.

SQLite is always available. PostgreSQL is available with the postgres cargo feature; the backend is chosen from the database URL (postgres:// or postgresql:// selects PostgreSQL, anything else is a SQLite path).
